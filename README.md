# 🚀 Portfolio William Roseno

Portfolio profissional de William Roseno, especialista em **Análise de Dados**, **Business Intelligence**, **Automação de Processos** e **Desenvolvimento Web**.

## 📊 Visão Geral

Um portfólio moderno e responsivo que apresenta serviços de:
- **Dados & BI** - Power BI, SQL, Excel, dashboards executivos
- **Automação** - Python, automação de processos, eficiência operacional
- **Sites & Landing Pages** - HTML, CSS, JavaScript, UX estratégica
- **Limpeza & Tratamento de Dados** - Planilhas, validação, padronização

Desenvolvido com **HTML5**, **CSS3** e **JavaScript vanilla**, com design premium corporativo e animações sofisticadas.

## 🚀 Como Usar

1. **Clonar o repositório:**
```bash
git clone https://github.com/williamroseno1/portfolio.git
cd portfolio
```

2. **Abrir no navegador:**
   - Abra `index.html` diretamente no navegador
   - Ou use um servidor local:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js
   npx http-server
   ```

3. **Acesso:**
   - Abra `http://localhost:8000` no navegador

## 📱 Responsividade

O projeto é totalmente responsivo:
- **Desktop** (1024px+) - Layout completo com 4 colunas de serviços, 3 projetos
- **Tablet** (640px - 1024px) - 2 colunas adaptadas
- **Mobile** (até 640px) - Layout em coluna única, otimizado

## 🎨 Customização

### Cores (CSS Variables)
No arquivo `src/css/style.css`, você pode personalizar:
```css
:root {
    --bg: #000000;              /* Background principal */
    --text: #ffffff;            /* Texto principal */
    --muted: rgba(255,255,255, 0.66); /* Texto secundário */
    --accent: #4f8cff;          /* Cor de destaque */
    --line: rgba(255,255,255, 0.08); /* Bordas */
}
```
